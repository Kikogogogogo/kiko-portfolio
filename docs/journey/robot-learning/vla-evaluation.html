Evaluating a Vision-Language-Action Policy

A vision-language-action policy maps observations and a language instruction to robot actions. A useful evaluation asks where the policy succeeds, how it fails, and whether those results repeat across conditions.

Define a measurable task

In a simulator, place a red block and a blue block on a table. Ask the robot to move the red block into a tray. Count success when the correct block stays in the tray after release, within a fixed time limit.

Control one change at a time

First repeat the baseline across several randomized initial positions. Then create separate test groups for camera viewpoint, lighting, object position, and instruction wording. Use the same evaluation configurations when comparing two policies.

Report what went wrong

Record the success count and trial count for each condition. Label failures such as choosing the wrong object, missing a grasp, dropping during transport, or timing out. Save the observation and action trace so a failed run can be reviewed and reproduced.
