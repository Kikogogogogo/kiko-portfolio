Binary Tree Maximum Path Sum

At each node, I ask two questions. What is the best path that turns here? What is the best path I can extend to the parent?

A path follows tree edges without visiting a node twice. It can start and end anywhere, and it must contain at least one node. The goal is to maximize the sum of its node values. Problem statement on LeetCode

Define what the recursion returns

rec(node) returns the best sum of a path that starts at node and goes downward. It includes node.val and may take one branch below it. The parent can attach this result as one straight continuation of its own path.

I visit the left and right children first. That makes this a postorder DFS. An empty child contributes zero, and I clamp a negative child gain to zero because leaving that branch out gives a better sum.

Update with two sides, return with one

  • Update the answer. node.val + left_gain + right_gain is the best complete path whose highest node is the current node. A path can enter from the left and leave through the right, so both sides can contribute.
  • Return to the parent. node.val + max(left_gain, right_gain) is the best extension the parent can use. If I kept both child branches and added the parent, the current node would have three path edges. A single path can have at most two.

Walk through an example

In this tree, the answer is 15 → 20 → 7, with a sum of 42.

     -10
     /  \
    9    20
        /  \
       15   7
  1. The leaves return their own values. Each is also a valid one-node path.
  2. At 20, the complete path scores 15 + 20 + 7 = 42. The recursion returns 20 + 15 = 35, the best single branch the parent can extend.
  3. At -10, the complete path through the root scores 9 - 10 + 35 = 34. The global best stays at 42.

Python solution

class Solution(object):
    def rec(self, root):
        if not root:
            return 0

        left_gain = max(self.rec(root.left), 0)
        right_gain = max(self.rec(root.right), 0)

        self.maxn = max(
            self.maxn,
            root.val + left_gain + right_gain
        )

        return root.val + max(left_gain, right_gain)

    def maxPathSum(self, root):
        self.maxn = float("-inf")
        self.rec(root)
        return self.maxn

Why it works

Every valid path has exactly one highest node, the one closest to the root. Below that node, the path uses at most one downward branch on each side. The recursive calls give the best branch starting at each child, so the candidate at the current node is the best path with that highest node. DFS checks that candidate at every node. The largest candidate is the answer.

All-negative trees and complexity

If all values are negative, both child gains are zero everywhere. Each node is considered by itself, so the answer is the largest node value. Initializing the best sum to negative infinity lets that negative value win.

Time: O(n) for n nodes, with constant work per node. Extra space: O(h) for the recursion stack, where h is the tree height. A balanced tree uses O(log n) stack space, and a chain uses O(n). In Python, a sufficiently deep chain can exceed the recursion limit. An explicit postorder stack avoids that limit.
