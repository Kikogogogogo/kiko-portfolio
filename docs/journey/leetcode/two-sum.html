Two Sum with a Hash Map

Given an array of integers and a target, return the indices of two distinct elements whose sum equals the target.

Look up the complement

At index i, subtract the current value from the target. If the difference is already in the hash map, the stored index and i form a valid pair. Check before storing the current value so the same index cannot be used twice.

def two_sum(nums, target):
    seen = {}
    for i, value in enumerate(nums):
        complement = target - value
        if complement in seen:
            return [seen[complement], i]
        seen[value] = i
    raise ValueError("No pair sums to the target")

Work through duplicates

For [3, 3] and target 6, the first pass stores 3 → 0. The second pass finds the first 3 and returns [0, 1].

Expected time is O(n) with constant-time hash lookups on average. The map uses O(n) extra space in the worst case.
