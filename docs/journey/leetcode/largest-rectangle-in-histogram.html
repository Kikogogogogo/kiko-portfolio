Largest Rectangle in a Histogram

I started by asking how wide a rectangle can grow before a shorter bar gets in the way.

Each bar has width one. A rectangle across several consecutive bars is limited by the shortest bar in that range. Checking every range while keeping a running minimum takes O(n²) time. LeetCode 84 problem statement

Wait until you know the right edge

As I scan left to right, I keep pairs of (start, height) in a stack. Each pair represents a height that can still extend to the right. Its start is the earliest index from which every bar seen so far is tall enough. The heights on the stack are strictly increasing.

When I reach a shorter bar at index i, I pop every taller height. Each popped rectangle ends just before i, so its area is height * (i - start). The current, shorter height can extend across those taller bars, so it inherits their earliest start.

If the top of the stack already has the same height, its start is at least as early. I keep that entry. After the scan, I use a virtual zero-height bar to finish any positive heights still waiting for a right edge.

Trace the moment that finds the answer

Index   0  1  2  3  4  5
Height  2  1  5  6  2  3
  1. At index 3, the stack holds (0, 1), (2, 5), and (3, 6). So far, the heights 5 and 6 can keep growing to the right.
  2. The height 2 at index 4 closes both. Height 6 gives 6 × (4 − 3) = 6. Height 5 gives 5 × (4 − 2) = 10.
  3. The new entry is (2, 2) because both taller bars to its left can support height two. No later rectangle exceeds 10.

Python solution

class Solution:
    def largestRectangleArea(self, heights):
        stack = []
        best = 0
        n = len(heights)

        for i in range(n + 1):
            height = heights[i] if i < n else 0
            start = i

            while stack and stack[-1][1] > height:
                left, previous_height = stack.pop()
                best = max(best, previous_height * (i - left))
                start = left

            if not stack or stack[-1][1] < height:
                stack.append((start, height))

        return best

Why it works

Any optimal rectangle can be raised to the height of its shortest bar. At that height, making the rectangle as wide as possible means extending until a shorter bar or the edge of the array stops it. The stack retains the earliest viable start and waits for that right edge. Equal heights can share the earliest start, so each candidate height is evaluated at its maximum width.

Time is O(n) because each entry is pushed and popped at most once. Extra space is O(n) for the stack. The final zero does not change the input.

Use the same idea in a binary matrix

For each row, track how many consecutive ones end at that row in each column. Increment a column's height on a one and reset it to zero on a zero. The resulting heights form a histogram. Every all-ones rectangle ends on some row, so running the stack algorithm at each row checks every possible bottom edge. This takes O(rows × columns) time and O(columns) extra space.
