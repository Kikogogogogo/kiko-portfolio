Building an Agent You Can Monitor

Consider an agent that answers project questions from a collection of approved documents. Give it one read-only search tool and require a source citation for each factual answer.

Trace each run

Record a run ID, tool name, response status, latency, and source IDs. Link each tool call to the parent run. Redact sensitive input and avoid retaining full documents in logs. A trace should show whether the agent found enough evidence to answer.

Bound the workflow

Set a tool-call budget and a timeout. If search returns no relevant results, surface that limitation to the user. Keep document permissions in the search service and validate each tool call on the server.

Evaluate the behavior you want

Build a small test set with answerable questions, ambiguous requests, empty results, and tool timeouts. Check citation accuracy, which failures are visible to the user, and whether the run stays within its budget. Compare those results after each change to the workflow.
